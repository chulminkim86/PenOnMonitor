# PenOnMonitor — 바로 쓰는 필기 도구

문서·영상·웹페이지 등 지금 보고 있는 화면 위에 바로 필기하거나, 화면 전체를
흰 판으로 덮고 판서한다. Windows 전용.

## 실행

```
ScreenPen 실행.bat
```

## 세 가지 상태

| 상태 | 화면 | 마우스 |
|---|---|---|
| **통과 모드** (기본) | 필기 내용만 화면 위에 떠 있음 | 아래 프로그램으로 그대로 통과 |
| **그리기 모드** | 화면을 순간 캡처해 배경으로 고정, 파란 테두리 | 오버레이가 받아서 필기 |
| **화이트보드** | 화면 전체를 흰 판으로 덮음, 확대/축소 가능 | 오버레이가 받아서 판서 |

- **그리기 모드** — 툴바 오른쪽 스위치 또는 `F8`
- **화이트보드** — 툴바의 `화이트보드` 버튼 또는 `Ctrl+0`. 그리기가 켜져 있든
  꺼져 있든 곧바로 전환된다.
- **Esc** — 어느 상태에서든 전부 해제한다. 화이트보드에서 나오고, 그리기를 끄고,
  **화면에 한 필기를 지운 채** 대기 상태로 돌아간다. 화이트보드 판서는 남는다.
  실수로 지웠으면 그리기를 켜고 `Ctrl+Z`로 되살릴 수 있다.

**필기는 두 벌로 따로 보관된다.** 화면에 한 필기와 화이트보드 판서는 서로 섞이지
않고 되돌리기 이력도 각각이다. 화이트보드에서 나갔다가 다시 들어와도 판서와
확대율·위치가 그대로다. `전체지우기`와 `지우개`는 지금 보고 있는 판만 지운다.

툴바는 어떤 상태에서도 항상 보이며, 상태를 전환해도 사라지거나 깜빡이지 않는다.

## 단축키

전역 단축키 — 초점이 어디에 있든 동작한다.

| 키 | 동작 |
|---|---|
| `F8` | 그리기 모드 켜기/끄기 |
| `Ctrl+0` | 화이트보드 켜기/끄기 |
| `Esc` | 전부 해제 (화이트보드 판서는 유지) |
| `F9` | 전체 지우기 |
| `Ctrl+Alt+S` | PNG로 저장 |
| `Ctrl+Alt+Q` | 종료 |

`Esc`는 **되돌릴 상태가 있을 때만** 가로챈다. 그리기·화이트보드가 켜져 있거나
화면에 필기가 남아 있는 동안에만 잡고, 대기 상태가 되면 즉시 놓아주므로 평소
다른 프로그램의 `Esc`를 방해하지 않는다.

| 키 | 동작 |
|---|---|
| `Ctrl+1` ~ `Ctrl+4` | 펜 / 지우개 / 사각 / 형광 |
| `Alt+1` ~ `Alt+3` | 검정 / 빨강 / 파랑 |
| `Ctrl+휠`, `Ctrl+PageUp`/`PageDown` | 굵기 1~50pt |
| `휠`, `PageUp`/`PageDown` | 화이트보드 확대 / 축소 |
| `H` | 화이트보드 손 도구 — 끌어서 이동 |
| `Ctrl+Z` / `Ctrl+Y` | 되돌리기 / 다시 실행 (툴바에는 두지 않았다) |
| 가운데 버튼 드래그 | 화이트보드 이동 (손 도구를 켜지 않아도 된다) |
| 오른쪽 클릭 | 전부 해제 (`Esc`와 같다) |

툴바의 각 버튼에 마우스를 올리면 해당 단축키가 툴팁으로 뜬다.

## 도구와 색상

- **펜** — 자유 곡선
- **지우개** — 커서가 닿은 획을 통째로 지운다
- **사각** — 드래그하는 동안 미리보기가 따라온다
- **형광** — 반투명(디더링) 굵은 선. **색상 선택과 무관하게 항상 노란색**
  (`#FFE24D`)이다.

| 키 | 이름 | 값 |
|---|---|---|
| `Alt+1` | 검정 (기본) | `#0D0D0D` |
| `Alt+2` | 빨강 | `#A20000` |
| `Alt+3` | 파랑 | `#2569A7` |

### 굵기

굵기 메뉴는 없다. **`Ctrl+휠`로 1pt부터 50pt까지 연속으로** 고르며, 그리기 모드와
화이트보드에서 똑같이 동작한다. 굵기를 바꾸는 동안 커서 옆에 실제 크기의 원과
`12 pt` 같은 숫자가 잠깐 떠서 눈으로 확인할 수 있다.

**굵기는 도구마다 따로 기억한다.** 기본값은 펜 5pt, 사각 5pt, 형광 24pt,
지우개 20pt이다. 형광을 굵게 써 두고 펜으로 돌아와도 펜 굵기는 그대로다.

## 화이트보드

- **확대/축소** — 그냥 휠을 돌린다. 커서 아래 지점을 고정한 채 확대되고, 배율은
  25%~800% 범위다.
- **이동** — `H`를 눌러 손 도구를 켜면 왼쪽 버튼으로 끌어 옮길 수 있다. 손 도구가
  켜지면 커서가 손 모양으로 바뀐다. 다시 `H`를
  누르거나 도구를 고르면 풀린다. 손 도구를 켜지 않아도 가운데 버튼 드래그로 옮길
  수 있다.
- 획의 굵기도 배율을 따라간다.

## 저장

`~/Pictures/ScreenPen/screenpen_YYYYMMDD_HHMMSS.png`에 저장된다. 툴바, 테두리,
굵기 표시는 빠진다. 통과 모드에서 저장하면 그 순간의 실제 화면 위에
필기가 얹힌 상태로, 화이트보드에서 저장하면 흰 판과 판서만 캡처된다.

# PenOnMonitor — 바로 쓰는 필기 도구

문서·영상·웹페이지 등 지금 보고 있는 화면 위에 바로 필기하거나, 화면 전체를
흰 판으로 덮고 판서한다. Windows 전용.

## 실행

두 가지 판이 있다. 기능과 단축키는 같고 그리는 방식이 다르다.

```
ScreenPen.bat          Tk 판. 파이썬과 Pillow 만 있으면 된다.
ScreenPen Qt 실행.bat  Qt 판. 획이 매끈하고 확대가 부드럽다. 권장.
```

Qt 판은 `pip install PySide6-Essentials` 가 필요하다.

## 세 가지 상태

| 상태 | 화면 | 마우스 |
|---|---|---|
| **통과 모드** (기본) | 필기가 화면에서 감춰짐 | 아래 프로그램으로 그대로 통과 |
| **그리기 모드** | 화면을 순간 캡처해 배경으로 고정, 파란 테두리 | 오버레이가 받아서 필기 |
| **화이트보드** | 화면 전체를 흰 판으로 덮음, 확대/축소 가능 | 오버레이가 받아서 판서 |

- **그리기 모드** — 툴바 오른쪽 스위치 또는 `F8`
- **화이트보드** — 툴바의 `화이트보드` 버튼 또는 `Ctrl+0`. 그리기가 켜져 있든
  꺼져 있든 곧바로 전환된다.
- **Esc** — 어느 상태에서든 전부 해제한다. 화이트보드에서 나오고, 그리기를 끄고,
  **화면에 한 필기를 지운 채** 대기 상태로 돌아간다. 화이트보드 판서는 남는다.
  실수로 지웠으면 그리기를 켜고 `Ctrl+Z`로 되살릴 수 있다.

**필기는 두 벌로 따로 보관된다.** 화면에 한 필기와 화이트보드 판서는 서로 섞이지
않고 되돌리기 이력도 각각이다. 화이트보드에서 나갔다가 다시 들어와도 판서와
확대율·위치가 그대로다. `전체지우기`와 `지우개`는 지금 보고 있는 판만 지운다.

**그리기를 끄면 필기가 화면에서 사라지고, 다시 켜면 그대로 되살아난다.** 지우는
것이 아니라 감추는 것이라 켜고 끄기를 반복해도 내용은 그대로다.

**그리기가 꺼져 있는 동안에는 메모 말고 아무것도 동작하지 않는다.** 도구·색상·
화이트보드·전체지우기·저장은 눌러도 반응하지 않고 흐리게 표시된다.

툴바는 어떤 상태에서도 항상 보이며, 상태를 전환해도 사라지거나 깜빡이지 않는다.

## 단축키

전역 단축키 — 초점이 어디에 있든 동작한다.

| 키 | 동작 |
|---|---|
| `F8` | 그리기 모드 켜기/끄기 |
| `Ctrl+0` | 화이트보드 켜기/끄기 |
| `Esc` | 전부 해제 (화이트보드 판서는 유지) |
| `F9` | 전체 지우기 |
| `Ctrl+Alt+S` | PNG로 저장 |
| `Ctrl+Alt+Q` | 종료 |

`Esc`는 **되돌릴 상태가 있을 때만** 가로챈다. 그리기·화이트보드가 켜져 있거나
화면에 필기가 남아 있는 동안에만 잡고, 대기 상태가 되면 즉시 놓아주므로 평소
다른 프로그램의 `Esc`를 방해하지 않는다.

| 키 | 동작 |
|---|---|
| `Ctrl+1` ~ `Ctrl+4` | 펜 / 지우개 / 사각 / 형광 |
| `Alt+1` ~ `Alt+3` | 검정 / 빨강 / 파랑 |
| `Ctrl+휠`, `Ctrl+PageUp`/`PageDown` | 굵기 1~50pt |
| `휠`, `PageUp`/`PageDown` | 화이트보드 확대 / 축소 |
| `H` | 화이트보드 손 도구 — 끌어서 이동 |
| `Ctrl+Z` / `Ctrl+Y` | 되돌리기 / 다시 실행 (툴바에는 두지 않았다) |
| 가운데 버튼 드래그 | 화이트보드 이동 (손 도구를 켜지 않아도 된다) |
| `Ctrl` + 왼쪽 드래그 | 손 도구 — 일반 필기·화이트보드 모두 (Qt 판) |
| 오른쪽 클릭 | 전부 해제 (`Esc`와 같다) |

툴바의 각 버튼에 마우스를 올리면 해당 단축키가 툴팁으로 뜬다.

## 도구와 색상

- **펜** — 자유 곡선
- **지우개** — 커서가 닿은 획을 통째로 지운다
- **사각** — 드래그하는 동안 미리보기가 따라온다
- **형광** — 반투명(디더링) 굵은 선. **색상 선택과 무관하게 항상 노란색**
  (`#FFE24D`)이다.

| 키 | 이름 | 값 |
|---|---|---|
| `Alt+1` | 검정 (기본) | `#0D0D0D` |
| `Alt+2` | 빨강 | `#A20000` |
| `Alt+3` | 파랑 | `#2569A7` |

### 굵기

굵기 메뉴는 없다. **`Ctrl+휠`로 1pt부터 50pt까지 연속으로** 고르며, 그리기 모드와
화이트보드에서 똑같이 동작한다. 굵기를 바꾸는 동안 커서 옆에 실제 크기의 원과
`12 pt` 같은 숫자가 잠깐 떠서 눈으로 확인할 수 있다.

**굵기는 도구마다 따로 기억한다.** 기본값은 펜 5pt, 사각 5pt, 형광 24pt,
지우개 20pt이다. 형광을 굵게 써 두고 펜으로 돌아와도 펜 굵기는 그대로다.

## 화이트보드

- **확대/축소** — 그냥 휠을 돌린다. 커서 아래 지점을 고정한 채 확대되고, 배율은
  25%~800% 범위다.
- **이동** — `H`를 눌러 손 도구를 켜면 왼쪽 버튼으로 끌어 옮길 수 있다. 손 도구가
  켜지면 커서가 손 모양으로 바뀐다. 다시 `H`를
  누르거나 도구를 고르면 풀린다. 손 도구를 켜지 않아도 가운데 버튼 드래그로 옮길
  수 있다.
- 획의 굵기도 배율을 따라간다.

## 메모

툴바의 `메모` 버튼으로 여닫는다. 윈도우 메모장 수준의 단순한 글쓰기 창이고,
가장자리를 끌어 크기를 자유롭게 바꾼다.

- **자리와 크기** — 툴바 바로 아래, 가로세로 모두 툴바 너비의 절반인 정사각형.
  창 가운데가 툴바의 `메모` 버튼 가운데에 오도록 놓인다.
- **글자 크기** — `Ctrl+휠` 로 8pt에서 96pt까지.
- **항상 띄워놓기** — 창 위쪽 체크상자(기본 켜짐). 켜면 다른 어떤 창도 메모를
  가리지 못하고 **바탕화면 보기(Win+D)를 눌러도 사라지지 않는다.** 도구 창이라
  제목 표시줄이 작고 최소화 단추가 없다. 끄면 평범한 창이 된다.
- **내용 보존** — 창을 닫아도 남고, 입력이 멈추면 `memo.txt` 에 자동 저장된다.

## 저장

Tk 판은 `~/Pictures/ScreenPen` 에, Qt 판은 **실행 파일 옆 `captures/`** 에
`screenpen_YYYYMMDD_HHMMSS.png` 로 저장한다. USB 에 담아 쓸 때 캡처가 함께
따라다니도록 한 것이다. 툴바, 테두리,
굵기 표시는 빠진다. 통과 모드에서 저장하면 그 순간의 실제 화면 위에
필기가 얹힌 상태로, 화이트보드에서 저장하면 흰 판과 판서만 캡처된다.

## Qt 판이 다른 점

Tk 캔버스는 안티에일리어싱이 없고 CPU 로 그린다. 획이 계단처럼 거칠고 확대는
획이 쌓일수록 느려졌다. Qt 판은 그리는 계층만 PySide6 + OpenGL 로 바꾼 것이다.

| | Tk 판 | Qt 판 |
|---|---|---|
| 획 가장자리 | 계단 그대로 (밝기 2단계) | 안티에일리어싱 (6~13단계) |
| 확대 · 획 800개 | 63 ms/프레임 | **13.6 ms** |
| 확대 · 획 300개 | 27.5 ms | **13.6 ms** |
| 획 모양 | 점을 직선으로 연결 | Catmull-Rom 곡선 + 손떨림 보정 |
| 형광펜 | 디더링으로 반투명 흉내 | 진짜 알파 |
| 그리기 모드 | 화면을 캡처해 정지 | **정지 없음. 살아 있는 화면 위에 그린다** |

확대가 뷰 변환 한 번이라 비용이 획 수를 따라가지 않는다. 재생 중인 영상이나
스크롤 위에 그대로 그릴 수 있는 것도 Qt 판에서만 된다.

## USB 에 담아 쓰기

파이썬이 없는 PC 에서도 쓰려면 단일 실행 파일로 묶는다.

```
build_exe.bat
```

PyInstaller 가 필요하다 (`pip install pyinstaller`). 결과물은 Dropbox 밖인
`%USERPROFILE%\ScreenPen_build\dist\PenOnMonitor.exe` 에 생긴다.

| 방식 | 크기 | 시작 시간(SSD) |
|---|---|---|
| 폴더 (216개 파일) | 152 MB | 0.33초 |
| 단일 exe | 61.8 MB | 2.2초 |
| **단일 exe, numpy 제외** | **47.6 MB** | **2.0초** |

USB 에는 단일 exe 가 낫다. 시작 시간만 보면 폴더가 빠르지만 그건 내장 디스크
기준이고, USB 에서는 216개 파일을 매번 읽는 쪽이 더 불리하다. 단일 exe 는
파일 하나를 순차로 읽고 압축은 로컬 임시 폴더에서 푼다.

쓰지 않는 numpy 가 Pillow 를 통해 27MB 딸려 들어오므로 빼면 62 -> 48MB 가 된다.

메모·설정·로그·캡처는 **실행 파일 옆에** 쌓인다. 그래야 USB 를 따라다닌다.
얼린 exe 에서 `__file__` 은 임시 폴더를 가리키므로 그대로 쓰면 메모가 실행할
때마다 날아간다. USB 가 쓰기 금지면 사용자 폴더로 물러난다.

서명이 없으므로 처음 실행할 때 SmartScreen 경고가 뜰 수 있다.
